## La règle de la série

**Une vidéo = un bénéfice.** Le format est identique sur les 6 vidéos pour créer une signature reconnaissable :

1. **Hook** (0–3 s) — étonnement, accroche
2. **Concept** (3–8 s) — le bénéfice annoncé
3. **Démo** (8–16 s) — screen recording en vrai
4. **Wow** (16–21 s) — le moment choc
5. **Contraste** (21–26 s) — « Le cahier, c'est fini »
6. **CTA** (26–31 s) — « Écris LISSAFI en commentaire »

## Mode d'emploi ElevenLabs

1. **Copie le bloc « Texte VO »** (dans les balises ``` ```) de chaque vidéo et colle-le dans ElevenLabs.
2. **Voix** : masculine, jeune, chaleureuse, avec un accent français naturel (un accent africain francophone est un plus si la voix existe).
3. **Réglages recommandés** (à ajuster selon la voix choisie) :
   - **Stability** : 30–40 (plus bas = plus d'émotion, plus de variations)
   - **Style Exaggeration** : 70–80 (rend les montées et les chutes expressives)
4. **Ponctuation = émotion** (ElevenLabs la traduit en prosodie) :

| Signe | Effet produit |
|---|---|
| `...` | Pause, hésitation, suspense |
| `!` | Choc, punch (1 ou 2 max par vidéo, sinon ça crie) |
| `?` | Question, accroche |
| Phrase courte | Tension, rythme |
| Retour à la ligne | Pause naturelle, respiration |

5. **Ne mets jamais d'emojis ni de mots entre crochets** dans le texte TTS : ça serait lu à voix haute.
6. **Si la lecture dépasse 31 s** : raccourcis les phrases du milieu (jamais le hook, jamais le CTA).

## Le ton à respecter sur tout

- Français parlé, tutoiement, **ton « frérot »** — comme si tu parlais à un pote au marché.
- Toujours les prix en **FCFA**.
- **Zéro formule de pub** : pas de « simple », « efficace », « révolutionnaire », pas de listes 1-2-3.
- Chaque vidéo a une **arc émotionnel** : curiosité → surprise → soulagement → confiance → action.
